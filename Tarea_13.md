Los entregables son
1. Genere un nuevo proyecto Spring Boot utilizando Spring Initializer e incluyendo Web dependency
2. Configuración de la base de datos utilizando el archivo application.properties
3. Implementa los modelos/entidades, que representen las entidades de la base de datos creadas en la tarea 12. Ejemplos: Usuario, Producto y/o Servicio
4. Implementa los repositorios necesarios para el proyecto. Ejemplos: UsuarioRepository, ProductoRepository y/o ServicioRepository,  que se conectan con la base de datos usando los modelos/entidades.
5. Implementa los métodos requeridos para cada repositorio de las operaciones CRUD en la base de datos.
6. Implementa los controladores necesarios para el proyecto. Ejemplos: UserController, ProductoController y/o ServicioController.
7. Implementa los endpoints necesarios en los controladores. Ejemplos: /login, /registro, /productos, /servicios. 
8. Implementación de JWT en el tiempo adicional que tendrán según ajustes daily
